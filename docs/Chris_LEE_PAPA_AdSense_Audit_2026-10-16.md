## 최우선 기준 — 실제 AdSense 탈락 사유 (고정)

**이 문서와 이후 모든 점검은 아래 두 가지 실제 거절 사유를 최우선·고정 판정 기준으로 삼는다. 다른 사유를 임의로 추가하거나 두 사유를 다른 표현으로 바꾸어 해석하지 않는다.**

1. **복제된 콘텐츠가 있는 화면에 Google 게재 광고**
   - 해당 화면에 반복·복제된 콘텐츠, 외부 자료의 단순 나열·임베드만 존재하는지 확인한다.
   - 페이지별 고유한 설명, 맥락, 분석, 제작자 경험 및 창작 기여가 실제로 있는지 확인한다.
   - 외부 영상·음악·자료를 사용했다는 사실만으로 자동 위반이라고 단정하지 않는다. 해당 화면에서 독창적인 부가 가치가 제공되는지를 판단한다.
2. **가치가 별로 없는 콘텐츠**
   - 방문자에게 제공하는 독창적 정보와 실질적 유용성이 충분한지 확인한다.
   - 내용의 깊이, 정확성, 완성도, 구체성, 제작자의 경험·관점 및 페이지 자체의 목적 달성 여부를 평가한다.
   - 페이지 수나 글자 수를 늘리는 것, 메타태그·디자인만 손보는 것은 콘텐츠 가치 개선으로 인정하지 않는다.

### 판정 원칙
- 모든 콘텐츠 페이지는 위 두 사유 각각에 대해 **양호 / 개선 필요 / 위험 / 확인 불가**로 판정하고, 실제 페이지 내용과 확인 근거를 기록한다.
- 페이지별로 중복·복제 요소와 독창적 기여를 구분해 기록한다. 외부 임베드의 개수만 세어 결론 내리지 않는다.
- 기술·색인·접근성·광고 코드·정책 페이지 점검은 필요한 보조 점검이다. 이는 위 두 탈락 사유와 동일한 콘텐츠 판정 항목이 아니며, 별도의 실제 증거 없이 탈락 원인이라고 단정하지 않는다.
- **‘사이트를 찾을 수 없음’은 이번에 확인된 실제 탈락 사유가 아니다.** 과거 문서/대화에서 이 사유를 이번 탈락 원인으로 기재하거나 추정하지 않는다.
- 사용자가 삭제했다고 확인한 페이지(예: Prompt Lab)는 실제 공개 URL·저장소 상태를 다시 확인하지 않고 점검 대상이나 개선 과제로 되살리지 않는다.
- 확인하지 않은 사항은 완료 처리하지 않는다. 페이지가 실제로 존재하는지, 공개되는지, 현재 내용이 무엇인지 먼저 확인한다.

- AdSense 계정 내부에서 `chrisleepapa.com`의 실제 상태/코드 감지/검토 버튼 상태

## 3. 근거와 해석

### 3.1 Google 공식 가이드

Google AdSense는 독창적이고 관련성 있는 콘텐츠, 명확하고 사용하기 쉬운 탐색, 좋은 사용자 경험을 권고한다. 외부 자료를 사용하는 경우에도 사이트 자체의 설명·분석·경험을 더해야 한다.

- 사이트 준비 가이드: https://support.google.com/adsense/answer/7299563?hl=ko
- 사이트가 준비되지 않았을 때의 점검 가이드: https://support.google.com/adsense/answer/12176698?hl=ko
- AdSense 정책 안내: https://support.google.com/adsense/answer/23921?hl=ko

이 사이트의 콘텐츠 점검은 오직 실제 거절 사유 두 가지에 맞춰 페이지별로 수행한다. 초기 HTML 렌더링·탐색·기술 항목은 콘텐츠 평가를 보조할 수 있지만, 별도 증거 없이 실제 거절 원인으로 단정하지 않는다.

### 3.2 홈페이지 소스 관찰

공개 홈페이지의 검색 가능한 텍스트에는 다음이 보임:
- 사이트 소개 및 창작 과정에 대한 설명
- 음악, 워십, 성경, 문학, 영상, SISTER SQUAD 프로젝트 링크
- 최근 Journal 항목
- Chris's News 소개와 “최신 뉴스 데이터를 불러오는 중입니다.”라는 초기 상태

소개 문구와 제작 기록은 긍정적이다. 다만 뉴스 본문이 클라이언트 로딩 이후에만 나타난다면, 검색/광고 검토기가 초기 본문을 충분히 읽지 못할 수 있어 확인이 필요하다. 이것이 실제 미승인 사유라고 단정할 수는 없다.

### 3.3 Sitemap 관찰

2026-10-16 당시 `main/sitemap.xml` 관찰 기록(현재 구성으로 간주하지 말 것):

- Music, Movie
- SISTER SQUAD Hub, Sistersquad, Sistersquad2, Yul, Jung (당시 기록이며 현재 URL·페이지 상태 재확인 필요)

이 절은 2026-10-16 당시의 기록이다. 과거에 언급된 개별 URL을 현재의 개선 과제로 자동 승계하지 않는다. 먼저 `develop`의 최신 sitemap과 실제 공개 URL 목록을 확인하고, 존재하는 페이지에 한해 고정된 두 콘텐츠 탈락 사유로 평가한다. sitemap·canonical·robots·HTTP 응답 검사는 별도의 보조 기술 점검으로만 기록한다.

## 4. 심사 신청 전 필수 작업 순서

### P0 — 신청 전에 반드시 확인 (보조 운영 점검)
1. **AdSense 계정의 사이트 항목**에서 사이트 URL이 `chrisleepapa.com`으로 정확한지 확인한다. 예전 Vercel 기본 도메인과 혼동하지 않는다.
2. AdSense 계정에서 새 도메인의 사이트 상태와 코드 인식 여부를 확인한다. 소스상 코드 존재만으로 완료 처리하지 않는다.
3. `https://chrisleepapa.com/ads.txt`, `/robots.txt`, `/sitemap.xml` 및 sitemap에 실제 포함된 URL의 응답·리디렉션·canonical을 확인한다.
4. 현재 실제 운영·공개 중인 페이지만 목록화한다. 삭제된 페이지나 내부 도구 페이지를 근거 없이 심사 대상/문제 페이지로 되살리지 않는다.
5. 모바일과 PC에서 실제 콘텐츠가 정상적으로 표시되는지, 주요 링크와 기능이 작동하는지 확인한다. 이 항목은 콘텐츠 두 사유와 구분해 보조 기록한다.

### P1 — 콘텐츠 품질 보강 (위 고정 기준 2개로만 판정)
1. 실제 공개·운영 중인 각 콘텐츠 페이지를 읽고, 복제·반복·단순 나열 여부와 제작자 고유의 설명·경험·창작 기여를 확인한다.
2. 각 페이지가 방문자에게 제공하는 독창적 정보·실질적 효용, 내용의 깊이·정확성·완성도를 확인한다.
3. 외부 자료·영상·음악·임베드는 출처와 맥락을 확인하고, 해당 페이지에 더해진 독창적 해설·분석·제작 기여가 무엇인지 기록한다.
4. 날짜·최신성이 중요한 페이지에 한해 정보의 최신성과 출처를 확인한다. 이 항목은 위 두 실제 탈락 사유를 평가하기 위한 근거로만 사용한다.

### P2 — 신청 직전
1. Search Console에서 sitemap 처리 상태와 주요 URL 검사 결과를 확인한다.
2. 주요 URL을 로그아웃/시크릿 창과 모바일 화면에서 열어 접근 제한이나 오류가 없는지 확인한다.
