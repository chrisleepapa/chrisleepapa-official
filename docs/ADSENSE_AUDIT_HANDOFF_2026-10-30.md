- 작성일: 2026-10-30
- 저장 브랜치: `develop`
- 저장소: `chrisleepapa/chrisleepapa-official`
- 운영 도메인: `https://chrisleepapa.com`
- 개발 도메인: `https://develop.chrisleepapa.com`
- 목적: 새 페이지를 만들지 않고 기존 사이트의 애드센스 거절 사유를 조사하고, 이후 어느 대화/작업 환경에서도 이어서 진행할 수 있도록 조사 내용과 다음 작업을 기록한다.

> **중요한 범위 고지**
> 이 문서는 GitHub `develop` 브랜치의 HTML/JavaScript 소스를 바탕으로 한 정적 사전 진단 기록이다. Google AdSense 심사 크롤러의 실제 렌더링 결과, 정책센터가 내부적으로 판정한 개별 URL, 모든 페이지의 브라우저 실측 결과까지 확인한 최종 감사는 아니다. 아래 위험도는 확정적인 정책 위반 판정이 아니라 우선 조사 순서다. 이번 진단 과정에서는 사이트 소스의 기능 변경을 하지 않았다.

## 1. 현재 애드센스 거절 사유

사용자가 2026-10-30에 공유한 AdSense 거절 사유:

1. **복제된 콘텐츠가 있는 화면에 Google 게재 광고**
   - 다른 사람의 콘텐츠를 복사/삽입하면서 논평, 선별, 기타 부가가치를 충분히 더하지 않은 화면에 광고를 허용하지 않는다는 안내.
2. **가치가 별로 없는 콘텐츠**
   - 독창적인 정보·도구·서비스, 지속적인 콘텐츠 관리, 실제 사용자 관심 및 이용 가치를 요구한다는 안내.

핵심 해석:
- 외부 YouTube/Spotify 임베드 자체가 자동으로 정책 위반이라는 뜻은 아니다.
- 페이지의 실질적인 가치가 외부 미디어 재생이나 링크에만 의존하는지, 창작자의 고유한 설명·경험·제작 과정·정보가 충분히 제공되는지가 중요하다.
- 출처 표기만으로 저작권/상업적 이용 권한이 자동 확보되는 것은 아니다.
- 광고를 제외하더라도 저작권 또는 콘텐츠 정책 문제가 자동으로 해결되는 것은 아니다.

## 2. 프로젝트 및 작업 원칙

- 저장소: `github.com/chrisleepapa/chrisleepapa-official`
- 주요 브랜치: `main`, `develop`
- 사용자가 선호하는 작업 흐름:
  1. `develop`에서만 조사 및 수정
  2. 개발 사이트에서 사용자가 직접 확인
  3. 승인 후 `main`에 반영
- 사용자가 요청하지 않는 한 `main`에 직접 수정하거나 배포하지 않는다.
- 새 페이지를 만들지 않는다. 기존 페이지와 기존 콘텐츠를 우선 활용한다.
- 불필요한 글자 수 늘리기, 중복 설명, 억지 SEO 문구 추가를 피한다.
- 변경 전 현재 파일/브랜치 상태를 다시 확인한다. 이 문서 작성 이후 코드가 변경되었을 수 있다.

## 4. 가장 중요한 정책/권리 확인 대상: Bible 및 Hymnal

조사 중 확인된 구조:
- `bible.html`은 성경과 찬송가를 함께 제공하는 기능성 페이지다.
- `js/bible-creator-story.js`에서 개역개정 성경 본문 및 저작권/상업적 이용 확인 필요성을 언급하는 설명을 확인했다.
- 성경 본문은 외부 GitHub 프로젝트 `stranger828/bibleAPI`의 JSON 데이터를 참조하는 구조가 포함되어 있고, 야고보서 일부는 별도 Supabase 데이터 연결이 사용되는 것으로 확인되었다.
- 찬송가 뷰어는 이미지/PDF 기반 악보 자료를 제공한다. 현재 확인된 페이지 소스에는 1~100장 관련 PDF/이미지 자료 연결이 나타났다. 사이트 기능은 전체 645장 목록을 전제로 구성되어 있다.
- 찬송가 가사·악보·편곡·편집물의 권리 및 온라인 게시/상업적 이용 허용 범위를 확인해야 한다.

권장 조치:
1. 성경 본문 데이터 공급자 및 원 저작권자의 이용 조건을 확인한다.
2. 개역개정 본문을 광고가 포함된 사이트에서 제공할 수 있는지 서면/공식 약관 근거를 확보한다.
3. 찬송가 악보·가사 파일 각각의 권리자, 배포 허용 범위, 상업적 이용 허용 여부를 확인한다.
4. 권리 확인이 끝날 때까지 Bible 페이지는 광고 제외를 우선 검토한다.
5. 권리 문제가 해소되지 않은 자료는 광고만 끄는 것으로 충분하지 않으므로 공개/제공 방식도 재검토한다.
6. `bible.html`에서 AdSense 스크립트가 중복 포함된 정황을 확인했다. 현재 파일을 다시 확인하고 중복 로딩을 제거한다.

주의: 위 내용은 권리 침해가 확정되었다는 뜻이 아니다. 라이선스/이용 약관 확인이 선행되어야 한다.

## 5. 광고 적용 제외를 우선 검토할 기능성/정책 페이지

정적 소스만으로 모든 페이지의 광고 적합성을 확정할 수는 없다. 다음 페이지는 사용자 경험과 Google 정책을 고려해 광고를 제거하거나 적용하지 않는 방향을 우선 검토한다.

| URL | 권장 검토 | 이유 |
|---|---|---|
| `/bible` | 광고 제외 우선 | 성경/찬송가 자료 권리 확인 필요 + 뷰어 기능 중심 |
| `/game` | 광고 제외 권장 | 게임 플레이 중심 화면 |
| `/tetris` | 광고 제외 권장 | 게임 플레이 중심 화면 |
| `/privacy` | 광고 제외 권장 | 정책 안내 페이지 |
| `/terms` | 광고 제외 권장 | 이용약관 페이지 |
| `/contact` | 광고 제외 권장 | 연락/협업 안내 페이지 |
| `/today` | 실제 화면 확인 후 판단 | 개인 기록·묵상·기능 중심 |
| `/wallpaper` | 콘텐츠 보강 후 판단 | 다운로드/임베드 중심이 될 가능성 |
| `/gameinfo` | 실제 본문 확인 후 판단 | 게임 소개·제작 설명의 독립적 가치에 따라 결정 |

광고 제외는 정책 위반의 확정 판정이 아니라 보수적인 운영 권고다. 페이지의 실제 렌더링 및 광고 슬롯 적용 상태를 확인하고 결정한다.

## 6. 외부 임베드/미디어 중심 페이지

소스에서 확인한 외부 미디어 사용 패턴:
- SisterSquad 관련 페이지: 자체 작품 설명과 영상/OST 연결이 공존.
- TuTuPuPuPiPi: YouTube 영상 및 Spotify OST 연결.
- Music: Spotify 앨범 임베드와 동적 제작 노트.
- Worship / English Worship: 음원 연결과 앨범/가사 소개.
- Movie: YouTube 영상 중심의 콘텐츠가 있으므로 영상별 제작 의도/과정 설명의 실제 노출 여부 확인.
- Wallpaper: 다운로드/영상 감상 중심이므로 독창적인 제작 설명이 충분한지 확인.
- Miracle Shot: 외부 미디어가 포함되더라도 자체 스토리와 캐릭터 소개가 충분히 존재하는 편.

점검 원칙:
- 외부 임베드를 일괄 삭제하지 않는다.
- 각 페이지에서 영상/플레이어 외에 독립적으로 읽을 수 있는 고유한 본문이 있는지 확인한다.
- 임베드 전후에 작품 설명, 제작자 경험, 제작 과정, 에피소드 정보 등 실질적인 부가가치가 있는지 확인한다.
- 외부 서비스의 콘텐츠를 그대로 옮겨 적는 방식으로 분량만 늘리지 않는다.

## 7. URL/색인 관련 점검

- 조사 당시 사이트맵은 약 24개 URL을 포함하는 것으로 확인되었다. 재작업 전 현재 `sitemap.xml`을 다시 읽어 정확한 URL 수를 확정한다.
- `/journal`은 `noindex, follow`가 확인되어 색인 의도와 설정이 일치하는지 점검한다.
- 과거 Search Console에서 `/about`의 Google 선택 표준 URL이 구 Vercel 도메인으로 잡혔던 이력이 있다. canonical, 내부 링크, 리디렉션, 구 도메인 색인 잔존 여부를 다시 확인한다.
- 구 Vercel 도메인은 공개 canonical로 사용하지 않는다는 기존 운영 원칙을 유지한다.
- 사이트맵에는 canonical URL만 포함한다.
- 실제 페이지의 `title`, `meta description`, `canonical`, `robots`를 URL별로 대조한다.
