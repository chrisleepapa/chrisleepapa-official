Set up your lock screen

Android: 기종에 따라 동영상 잠금화면 지원 여부가 다릅니다. 지원 기기에서는 갤러리에서 영상을 선택해 잠금화면으로 설정할 수 있습니다.

Android: Support varies by device. On supported phones, select the video in Gallery and set it as your lock-screen wallpaper.

iPhone: MP4 파일을 그대로 움직이는 잠금화면으로 설정할 수는 없습니다. Live Photo 형식이 제공되는 경우 iOS의 잠금화면 설정에서 적용할 수 있습니다.

iPhone: An MP4 alone cannot be set as a moving lock screen. If a Live Photo version is provided, you can apply it through iOS Lock Screen settings.
